# 민법 가이드 (Minbub Guide)

변리사 1차 민법개론 학습을 위한 AI 코칭 앱입니다. PDF 또는 TXT 학습 자료를 업로드하면,
내용을 논점 단위로 분리해 최대 10개의 10분 학습 세션으로 나누고 세션별로 핵심 요약, 유사 개념 비교,
기본/사례형/5지선다 문제, 자기설명 문제, 오답 포인트, 암기 한 줄, 복습 시점을 순서대로 안내합니다.

빌드나 서버 없이 `index.html` 파일 하나로 동작하는 단일 파일 앱입니다.

## 시작하기

1. `index.html` 파일을 더블클릭하거나 브라우저로 엽니다.
2. 우측 상단 ⚙ 버튼을 눌러 Anthropic API 키를 입력합니다 (필요하면 모델 ID도 변경).
3. "PDF/TXT 업로드" 버튼으로 학습 자료를 올리면 자동으로 세션 목차와 세션 1이 시작됩니다.

## 동작 방식

- PDF 텍스트 추출: [pdf.js](https://mozilla.github.io/pdf.js/)를 CDN으로 불러와 브라우저에서 바로 처리합니다.
- 코칭 로직: 세션 구성 규칙(10단계 순서), 정답 비공개 원칙, 기출/변형/AI생성 문제 구분 등이
  담긴 시스템 프롬프트와 함께 브라우저에서 Anthropic API(`/v1/messages`)를 직접 호출합니다.
- API 키는 이 브라우저의 `localStorage`에만 저장되며 Anthropic 서버 외에는 전송되지 않습니다.
  공용 PC에서는 사용 후 "초기화" 버튼으로 지우는 것을 권장합니다.

## 참고

- 추출 텍스트는 약 18만자까지 반영됩니다. 분량이 이를 초과하면 앞부분만 반영되고
  "다음 학습 묶음" 안내가 함께 표시됩니다.
- 스캔 이미지로만 이루어진 PDF는 텍스트 추출이 되지 않을 수 있습니다 (OCR 미지원).
- 인터넷 연결이 필요합니다 (pdf.js CDN, Anthropic API 호출).
