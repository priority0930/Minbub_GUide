# 빅분기 TYPE 3 — 10일 완성

빅데이터분석기사 실기 작업형 3유형(통계 분석) 대비용 학습 앱입니다. 빌드 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 들어 있는 것

- 14개 통계 템플릿(T01 단일표본 t검정 ~ T14 Mann-Whitney U): 개념, 가설, 필수 코드, 출력 속성, 자주 하는 실수
- 문제 42개(유형별 3개), 소문항 130개. 데이터는 `csv/`에 있고 정답은 `generate_problems.py`가 scipy·statsmodels로 계산
- 학습 모드 A~G: 개념 / 방법 선택 퀴즈(28문항) / 코드 빈칸 / 출력 해석 퀴즈(25문항) / 소문항 실전 / 30점 모의고사 / 오답만 재학습
- 함수 이름 → 출력 코드 → 수치 답 순서로 입력. 틀리면 유형 → 함수 → 속성 → 정답·해석 순으로 단계 피드백, 흔한 실수(Welch/합동분산 혼동, exp 누락, Yates 보정 등)는 오답 사유를 따로 알려줌
- 힌트 1·2단계, 정답 공개(함수 이름과 출력 코드를 먼저 입력해야 열림), 허용 오차 채점
- 10일 계획, 오답노트, 진행률, 누적 정답률, 가상 30점 모의고사(소문항당 5점, 실제 시험 배점과 별개), 10점 달성 표시
- 진행 기록은 브라우저 localStorage에 저장되고 설정에서 초기화

## Python 실행

[Python 실행] 버튼은 브라우저에서 Pyodide(약 30MB)를 CDN에서 불러와 코드를 실행합니다. 네트워크나 보안 정책으로 불러올 수 없으면 실행하지 않았다고 표시하고, 미리 계산된 정답으로만 채점합니다. CSV 복사/다운로드로 본인 Python이나 Colab에서 실행할 수도 있습니다.

## 문제 다시 만들기

```bash
pip install numpy pandas scipy statsmodels
python generate_problems.py
```

`data.js`와 `csv/*.csv`가 다시 생성됩니다. (생성 시 사용 버전: scipy 1.18.1, statsmodels 0.15.0)
